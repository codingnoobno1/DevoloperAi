# Dashboard (Home)

The Dashboard is the central hub of Syncro.Desktop, providing quick access to AI assistance and project management tools.

## Key Sections

### 1. AI Agent Assistant
*   **Prompt Interface**: Enter natural language commands for the AI.
*   **AI Modes**: Select between General Chat, Script Generation, and Stack-specific project creation.
*   **Script Generation & Execution**: Generate batch files or environment setup scripts and run them directly in a target workspace.
*   **Terminal Integration**: Option to open a terminal in the target directory post-execution.

### 2. Quick Start Tools
*   **Rapid Setup**: One-click configuration for common tech stacks like Python/Flask and Java/Maven.
*   **Package Manager Installers**: Shortcuts for installing Chocolatey and Scoop.

### 3. Environment Detection
*   **Real-time Scanning**: Lists all detected development tools (Node, Python, .NET, etc.) on the host machine.
*   **Status Indicators**: Shows versions and paths of available tools.
