# Git Repository Manager

The Git Manager tab provides deep insights and management tools for any local Git repository.

## Features
*   **Repository Analysis**: Load any local directory to verify if it's a valid Git repository.
*   **Remote Tracking**: Displays the primary remote URL for the repository.
*   **Detailed Status**: Shows the current branch status and pending changes.
*   **Language Statistics**: Automatically calculates the percentage of code in different programming languages (e.g., C#, HTML, CSS) within the repository.
*   **AI Insights**: Integrates with backend services to provide repository-specific metadata.
